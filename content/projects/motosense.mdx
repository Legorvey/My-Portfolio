## Overview

MOTOSENSE monitors vibration on the CVT (continuously variable transmission) of a motorcycle. A Raspberry Pi 3B reads an ADXL345 accelerometer over I2C and compares the readings with thresholds. An RGB LED and a buzzer show the result. When the Pi has internet access, it also sends the data to an InfluxDB database, and a web dashboard uses that data to show how vibration changes over time.

## Operating modes

**Local (offline).** The Raspberry Pi processes the vibration data itself. If vibration goes above the thresholds, the LED and buzzer react immediately. No internet connection is needed. The program runs as a background service (`motosense.service`).

**Remote (online).** When the Pi is connected to the internet, it synchronizes the data to InfluxDB. The web dashboard reads from it, so mechanical degradation can be followed over a longer period.

## Installation and calibration

- Check the service with `sudo systemctl status motosense.service`.
- If readings are inaccurate, adjust the offset values in `calibration.json`.
- Attach the casing to the CVT with cable ties. Mount the ADXL345 rigidly to the casing base so the data is accurate.
